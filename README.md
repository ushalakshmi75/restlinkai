# 🌍 ResistLink AI
### Community Mutual Aid & Disaster Response Hub

**ResistLink AI** is a responsive, community-focused web application designed to help people coordinate during emergencies and disasters. It connects people who need assistance with volunteers, emergency resources, and local community support.

Our mission is to build a smarter, safer, and more inclusive future through technology-driven community resilience.

## ✨ Features

- 🚨 **Emergency Mode** — A dedicated interface for urgent community needs.
- 🤖 **AI-Assisted Triage Simulation** — Demonstrates how incoming requests can be prioritized based on urgency.
- 🤝 **Community Mutual Aid** — Helps connect people requesting assistance with available support.
- 📍 **Resource Feed** — Displays sample community alerts, needs, and available resources.
- ♿ **Accessibility-Focused Design** — Designed with readable typography, clear contrast, and inclusive user interactions.
- 📱 **Responsive UI** — Works across desktop, tablet, and mobile screens.
- ⏳ **Loading Skeletons** — Improves the perceived responsiveness of the interface.
- 🧪 **Sample Data** — Enables demonstration of the core user experience without a live backend.

## 🎯 Problem Statement

During natural disasters and other emergencies, communities may struggle to coordinate volunteers, locate resources, and identify urgent needs. Information can become fragmented, and vulnerable people may have difficulty accessing assistance.

ResistLink AI proposes a centralized digital hub to make community support more organized, accessible, and responsive.

## 💡 Our Solution

ResistLink AI provides a unified interface for community assistance, emergency updates, resource discovery, and simulated intelligent request prioritization. The prototype demonstrates how digital technology can support faster coordination and more inclusive disaster response.

## 🛠️ Technology Stack

- **HTML5** — Page structure
- **Tailwind CSS** — Responsive styling
- **JavaScript** — Interactive UI and triage simulation
- **Tailwind CSS CDN** — Development-time styling dependency

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git
- A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/ResistLink-AI.git
   ```

2. Navigate to the project folder:

   ```bash
   cd ResistLink-AI
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and use the **Live Server** extension to run the website locally.
